Place custom 44.1 kHz 16-bit PCM .wav or .ogg files here using these exact names:
- engine_idle.wav
- engine_low_rpm.wav
- engine_high_rpm.wav
- turbo_spool.wav
- blowoff_valve.wav
- sports_exhaust.wav
- engine_decel.wav

When these files are absent, TURBO DRIVE automatically uses its built-in ProceduralSynthEngine.
